# Documentation Rules

Docs use Documenter.jl + DocumenterVitepress. Procedure and warning triage: the `build-docs` skill.

```sh
julia --project=docs --startup-file=no docs/make.jl
```

## Sources and generated pages

- Pages live in `docs/src/` (`index.md`, `man/`, `assets/`). A new page must be added to the `pages` list in `docs/make.jl` or it will not appear in the navigation.
- `docs/make.jl` **regenerates** `man/license.md`, `security.md`, `authors.md`, `code_of_conduct.md` and `contributing.md` from the repo-root `LICENSE.md`, `SECURITY.md`, `AUTHORS.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`. Edit the root file, never the generated page.
- `man/diffusion2D_periodic.md`, `man/ShearBand2D.md` and `man/Blankenbach.md` are generated by Literate.jl from three miniapps (`miniapps/README.md` lists them). Edit the miniapp, rebuild, and review `git diff docs/src/man/` before committing.
- `docs/paper/` is the JOSS paper. Keep it separate from the user docs.
- Never commit `docs/build/` or `docs/site/`.

## API reference pages

- `docs/src/man/api/*.md` use `@autodocs` blocks with an explicit `Pages = [...]` list of **source file paths**. A new source file with docstrings must be added to the right page's `Pages` list, or its docstrings never render and `checkdocs` reports them missing.
- `warnonly = [:missing_docs, :cross_references]`: missing docstrings and broken `@ref`s are warnings, not failures. Fix the ones your change introduces.
- The docs environment loads `GeoParams` and `JustPIC`, so examples can use them.

## Style

- Use Documenter cross-references (`` [`name`](@ref) ``) and `@id` anchors rather than bare URLs to other pages.
- Docstring conventions: [docstring-rules](docstring-rules.md).
- When exported API changes, update the docstring and the relevant `docs/src/man/` page in the same PR. Examples should link to the existing guide pages and stay executable where practical.
- Do not narrate history ("previously", "now") in reference pages; describe current behavior.
