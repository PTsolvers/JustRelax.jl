# Citing JustRelax.jl

Use this selector to generate the citations for the software that contributed
to your work.

```@raw html
<CitationSelector />
```

The repository's [CITATION.cff](https://github.com/PTsolvers/JustRelax.jl/blob/main/CITATION.cff)
file provides machine-readable citation metadata for reference managers and
GitHub's citation tool.

## Data availability

Make the code, input files, and data needed to reproduce your results openly
available whenever possible. Deposit the exact JustRelax.jl version, model
configuration, input data, output data, and execution logs in a persistent
repository that issues a DOI, then cite that DOI in your publication.

## Acknowledgment

If appropriate for your work, use the following acknowledgment:

> The simulations were performed using JustRelax.jl, an open-source Julia
> package for geodynamic modeling with matrix-free solvers
> (https://doi.org/10.21105/joss.09365).
