# Getting help

Search this documentation and the existing [GitHub discussions](https://github.com/PTsolvers/JustRelax.jl/discussions) first; the answer may already be available.

- Ask usage, modeling, or design questions in [GitHub Discussions](https://github.com/PTsolvers/JustRelax.jl/discussions).

- Reach out to the main developers [Authors](@ref)
- Report reproducible bugs and request concrete changes through [GitHub Issues](https://github.com/PTsolvers/JustRelax.jl/issues). Include the JustRelax and Julia versions, selected backend, a minimal working example (MWE), and the expected and observed behavior.
- Report security vulnerabilities privately through the [security advisory form](https://github.com/PTsolvers/JustRelax.jl/security/advisories/new). Do not open a public issue for a vulnerability.

For contributing code, benchmarks, or documentation, see the [contribution guide](@ref Contributing).
