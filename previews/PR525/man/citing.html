The selector lists only Zenodo-backed JustRelax.jl releases. JustPIC.jl and GeoParams.jl use permanent Zenodo DOIs; their authors and title come from the packages' `.zenodo.json` files, and their year/version come from Zenodo.

The repository's CITATION.cff file provides machine-readable citation metadata for reference managers and GitHub's citation tool.

Data availability ​

Make the code, input files, and data needed to reproduce your results openly available whenever possible. Deposit the exact JustRelax.jl version, model configuration, input data, output data, and execution logs in a persistent repository that issues a DOI, then cite that DOI in your publication.

Acknowledgment ​

If appropriate for your work, use the following acknowledgment:

The simulations were performed using JustRelax.jl, an open-source Julia package for geodynamic modeling with matrix-free solvers (https://doi.org/10.21105/joss.09365).
